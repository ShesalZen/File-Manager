## Size interpretation

- The universal debug APK contains the shared application plus native libraries for all three supported ABIs; it is therefore larger than each ABI split.
- Its compressed payload by category is native 63.53 MiB, dex 41.45 MiB, and assets 19.62 MiB.
- Tectonic, ONNX Runtime, ML Kit OCR, and the Tectonic cache account for much of the native and asset payload.
- Prefer ABI-specific APKs for direct sideloading. A universal APK is useful only when one artifact must support ARMv7, ARM64, and x86_64 devices.
- A release build with R8/resource shrinking is the appropriate size baseline; the figures in this report are unminified debug artifacts and should not be treated as release sizes.
- Further reductions require product decisions: moving optional OCR/ONNX/Tectonic functionality to on-demand modules, shipping a smaller Tectonic cache, or removing one of the supported ABIs. ABI filters alone do not shrink the universal APK.
